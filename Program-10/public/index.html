💡 How OAuth 2.0 Works:

  1. Clicking login generates a cryptographically random state token (CSRF prevention).
  2. User is redirected to the Authorization Server to approve requested scopes.
  3. Server exchanges the returned authorization code for an access_token.
  4. Protected user profile is verified and an encrypted HTTP-Only session is established.
